# ARC-Catalog: Creación de la entidad Catalog Record 

## Contexto

Se busca crear una nueva entidad llamada Catalog Record que tenga el mismo comportamiento que 
la entidad Dataset, pero en el que crearemos un aspecto para guardar el xml del metadato correspondiente,
que luego un Dataset podrá tenerlo referenciado a partir de esta entidad

## Objetivo

Se busca crear una nueva entidad llamada Catalog Record con el mismo comportamiento de Dataset
y que luego le añadiremos un aspecto nuevo con structured properties para guardar el xml.

## Tareas

- [x] Crear la entidad Catalog Record en el modelo de metadatos
- [x] Crear la entidad en graphql y que sea reconocible e ingestable
- [ ] Incorporar esta nueva entidad a la UI en datahub-web-react
